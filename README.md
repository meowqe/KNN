# KNN: Классификация клиентов телеком-компании (pet-project)

## О проекте

Проект посвящен построению модели K-Nearest Neighbors (KNN) для классификации клиентов телекоммуникационной компании.
Цель — предсказать, к какой категории услуг (custcat) относится клиент на основе его демографических и поведенческих характеристик. Это задача многоклассовой классификации (4 категории клиентов).
В проекте выполнен полный цикл машинного обучения: от загрузки и анализа данных до предобработки, масштабирования признаков, обучения модели KNN, подбора гиперпараметра k и оценки качества.

---
Структура проекта

1. Импорт библиотек и загрузка данных
- Загрузка датасета teleCust.csv (1000 клиентов)
- Первичный осмотр данных

2. Исследовательский анализ данных
- Изучение распределения всех признаков
- Анализ баланса классов целевой переменной custcat
- Выявление потенциально избыточных признаков

3. Предобработка данных
- Удаление сильно коррелирующих признаков (ed, employ)
- One-Hot Encoding категориальных переменных (region, reside)
- Масштабирование числовых признаков (StandardScaler)

4. Подготовка данных для модели
- Разделение на признаки (X) и целевую переменную (y)
- Разбиение на обучающую и тестовую выборки (80/20)

5. Построение и оценка модели KNN
- Обучение модели KNeighborsClassifier
- Эксперименты с разными значениями k (k=4, k=6 и др.)
- Оценка качества модели с помощью метрики Accuracy

---
## Инструменты и библиотеки

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
